If a system failure occurs at time $t$, the components may be inspected in some order to identify the failed component. The order that minimizes the expected number of inspections is to inspect components in the order of decreasing probability of being the cause. We denote this order by $\orderfunc$, a one-to-one function that maps inspection order $n \in \{1, \ldots, m\}$ to a component $k \in \{1, \ldots, m\}$, implicitly defined as
\begin{equation}
\orderfunc \left(i \given t\right) < \orderfunc\left(j \given t\right) \iff \pmf_{\rv{K} \given \sv}\left(i \given t, \tparam\sysparam\right) > \pmf_{\rv{K} \given \sv}\left(j \given t, \tparam\sysparam\right)\,.
\end{equation}
Let the discrete random variable $\rv{N}$ denote the number of inspections. The conditional probability mass $\rv{N}$ given $\sv = t$ is given by
\begin{equation}
\label{eq:expo_P_N_sigma}
    \pmf_{\rv{N} \given \sv}\left(n \given t, \tparam\sysparam\right) =
    \pmf_{\rv{K} \given \sv}\left(\orderfunc \left(n \given t \right) \given t, \tparam\sysparam \right)\,.
\end{equation}
The expected number of inspections is given by the expectation
\begin{equation}
\scalarstat(\tparam\sysparamvec) = \sum_{n=1}^{m} n \cdot \pmf_{\rv{N} \given \sv}\left(n \given t, \vectomat{\tparam\sysparamvec}\right)\,,
\end{equation}
which is approximately given by the \emph{entropy} of $\rv{K}$ given $\sv = t$,
\begin{equation}
    \entropy(\rv{K} \given \sv = t) = -\sum_{n=1}^{m} 
\end{equation}
